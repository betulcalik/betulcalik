# Hi, I'm Betül 👋

I'm a software engineer and iOS developer. I build native iOS apps in Swift —
most of them with clean architectures like MVVM and VIPER — and I've also
worked on hybrid iOS/Unity projects and Swift packages for networking.
On the research side, I've published work on modified particle swarm
optimization (MPSO) and image analysis with k-means clustering.

Portfolio, blog, and contact: **[betulcalik.dev](https://betulcalik.dev)**

## Selected work

- **[mooviez](https://github.com/betulcalik/mooviez)** —
  search movies and watch their YouTube trailers, built with VIPER.
- **[github-repo-list-viewer](https://github.com/betulcalik/github-repo-list-viewer)** —
  search GitHub users and browse their repositories, built with MVVM.
- **[APIManager](https://github.com/betulcalik/APIManager)** —
  a Swift package that simplifies network requests.
- **[ios-unity-integration](https://github.com/betulcalik/ios-unity-integration)** —
  embedding a Unity game inside a native iOS app.
