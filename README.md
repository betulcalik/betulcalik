I'm a software engineer from Turkey. I build native iOS apps in Swift — SwiftUI and UIKit, MVVM and VIPER architectures — and lately I've been building **AI-powered developer tooling**: agent skills and plugins that make coding agents do real work.

## 🔭 Currently

- **[apple-review-skill](https://github.com/betulcalik/apple-review-skill)** — an AI agent skill that audits iOS apps against Apple's App Store Review Guidelines (every rule, a UGC/social-media deep dive, real rejection cases, and the appeals playbook).
- **[opencode-pi-intercom](https://github.com/betulcalik/opencode-pi-intercom)** — an OpenCode plugin that joins OpenCode sessions to the pi/omp intercom broker, so multiple coding agents can message and delegate to each other on one machine.
- Shipping a SwiftUI, offline-first habit tracker built on GRDB.
